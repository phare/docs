The Phare MCP server connects AI assistants like Mistral, Claude, and ChatGPT to your organization with the [Model Context Protocol](https://modelcontextprotocol.io). Check which monitors are down, open an incident during an outage, or schedule a maintenance window, directly from your conversation.

Applications connected to the MCP server act as you: they have the permissions of your [role](/user-management#roles) and only access your projects. No API key is needed, you log in to Phare and approve the application the first time you connect it.

Use this URL to connect an application:

```
https://mcp.phare.io/mcp
```

## Requirements

- A Phare account with a verified email address.
- Access to at least one project. Admins and the owner access every project, other members access the [projects they are part of](/user-management#accessing-projects).
- An application supporting remote MCP servers with OAuth, like the ones below.

### Approving the connection

After you log in, Phare shows the name of the application, the site you will be sent to after approving, and your email address, organization and role. Click **Approve** to connect the application.

<Warning>
    Only approve a connection you just started yourself. Phare shows a warning when the connection was started by an application on your computer, as any application on your computer can start one.
</Warning>

## Using the MCP server

Once connected, ask your questions in plain words. For example:

- "Which monitors are down in my Production project?"
- "What was the uptime of the API monitor last month?"
- "Open an incident on the status page for the slow checkout, and post an update saying we are investigating."
- "Schedule a maintenance window on Sunday from 2:00 to 4:00 for the database monitors."
- "Create an HTTP monitor for https://example.com checking every minute."

The application calls [`whoami`](#account) first to find your role and projects, then the [tools](#tools) it needs to answer.

<Tip>
    If you have several projects, name the project in your request so the application uses the right one.
</Tip>

## Permissions

The MCP server follows your [role](/user-management#roles) and your projects, so an application can never do more than you can in the dashboard:

- **Tools**: The application only sees the tools your role can use. Viewers only see the tools reading data, responders also see the tools managing incidents and maintenance windows. Phare checks your permissions on every tool call, so a change to your role applies right away.
- **Projects**: The application only accesses the projects you can access. Most tools act on one of them through their `project_id` argument.
- **Credentials**: The MCP server can't manage API keys, invitations, members, roles, single sign-on, the organization settings or billing. Use the dashboard for these.

Each tool tells the application whether it reads, creates, or changes and deletes data. Most applications ask for your confirmation before changing or deleting anything.

## Tools

The tools run the endpoints of the [Phare API](/api-reference/introduction), with the same arguments, validation and responses. Click a tool to see all its arguments in the API reference.

The alert rules, monitors, reports, incidents, maintenance windows and status pages tools act inside a project and require a `project_id` argument: the ID of one of your projects, found with `whoami` or `list_projects`.

List tools return 20 results per page by default, up to 100 with the `per_page` argument. The application gets the next results with the `page` argument.

## Disconnecting an application

Your applications are listed in the connected applications section of your <a href="https://app.phare.io/user/settings#connected-applications" rel="nofollow">user settings</a>, with the site they send you to and when they were last active. Click the trash icon next to an application to disconnect it, it loses access to your account until you connect it again.

Phare also disconnects all your applications when:

- You change your password or your email address, or reset your password.
- You enable or disable two-factor authentication.
- Single sign-on is enabled or removed for your organization.

<Note>
    An application unused for 30 days must be connected again.
</Note>

## Security

You receive an email when an application is connected to your account, with the date, IP address and browser of the connection. If the connection is unexpected, [disconnect the application](#disconnecting-an-application), reset your password and contact [support@phare.io](mailto:support@phare.io) right away.

Phare uses the OAuth authorization code flow with PKCE. Access tokens expire after one hour, and only the known web applications and the applications running on your computer can connect.

## Rate limiting

The MCP server is rate limited to **100 requests per minute** across the organization. All members share the same limit, separate from the [API rate limit](/api-reference/introduction#rate-limiting).

---

If a tool is missing or a custom rate limit is needed, [contact support](mailto:support@phare.io). Phare can help find a solution that fits the use case.
